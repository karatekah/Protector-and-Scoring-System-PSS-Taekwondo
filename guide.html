01 · PRIMER COMBATE

De la configuración
a la segunda pantalla.

  1. Prepara la sesión. Introduce el evento, los competidores, de 1 a 5 rondas y una duración entre 00:10 y 09:59. Guardar abre el control.
  2. Abre la pantalla externa. Permite la ventana emergente, muévela al segundo monitor y activa Pantalla completa. Debe usar el mismo navegador y perfil que el control.
  3. Dirige el combate. Inicia o pausa el reloj. Registra de +1 a +6 puntos por decisión manual. Gam-jeom suma una penalización al atleta y un punto al rival; Impacto registra sin sumar puntos.
  4. Continúa o corrige. Siguiente ronda conserva los puntos acumulados. Deshacer revierte la última acción disponible y pausa el reloj sin devolver el tiempo transcurrido.
  5. Guarda y respalda. Guarda un resumen y exporta JSON desde Preparar combate. Nuevo combate archiva el actual antes de reiniciar.

02 · EXPECTATIVAS CLARAS

Hecho para
entrenar y exhibir.

La alpha ofrece puntuación manual, reloj, rondas, penalizaciones, impactos, deshacer, resúmenes, respaldo JSON y una pantalla externa de solo lectura.

El operador decide qué acción puntuar y cuándo terminar el combate. Los valores +1 a +6 son incrementos manuales: no asignan automáticamente una técnica ni representan una edición de un reglamento.

No incluye sensores, homologación WT, victorias por asalto, desempates, gestión de torneos, cuentas ni conexiones entre dispositivos. Compartir el enlace en otro equipo abre una sesión independiente.

La pestaña de control debe permanecer abierta. Al recargarla el reloj queda pausado. Usa la segunda ventana en la misma sesión del navegador; una ventana privada o un perfil distinto no comparte los datos.

03 · RESPALDO Y RECUPERACIÓN

El navegador guarda.
Tú conservas la copia.

El combate, las últimas 120 acciones y hasta 80 resúmenes se guardan en el almacenamiento local del sitio. Al alcanzar cada límite, se retiran primero los registros más antiguos.

Exporta JSON antes de borrar datos del navegador, cambiar de dominio o trasladarte a otro equipo. Importar JSON valida el archivo y pide confirmar antes de reemplazar los datos actuales. Solo acepta el formato de esta alpha y archivos de hasta 5 MB.

Los datos del prototipo v2/v3 se recuperan cuando son válidos: se conservan el combate y los resúmenes compatibles. El deshacer y los registros detallados del formato anterior no se migran; las claves antiguas se mantienen en el navegador.

La aplicación no incorpora cuentas, analítica ni envío de los combates a un servidor. Vercel recibe las solicitudes necesarias para servir la demo. Cualquier persona con acceso a tu perfil del navegador puede ver los datos locales.

04 · FUNDAMENTOS

El stack responde
al producto.

TypeScript estrictoLógica del combate tipada y separada de la vista.
Vite + CSSCompilación estática, tokens visuales y componentes nativos.
Web Locks + canales localesUn operador por perfil del navegador. Pantalla externa de solo lectura.
Vitest + PlaywrightReglas, respaldo, sincronización, navegador y accesibilidad automatizada.
GitHub Actions + VercelVerificaciones reproducibles y despliegue en el proyecto existente.
Node 24 LTS + npmHerramientas de desarrollo con versiones fijadas en el repositorio.

Esta alpha no necesita base de datos ni backend. Una futura conexión por red tendrá una autoridad de combate en el servidor; los canales locales actuales no sustituyen ese diseño.

05 · SIGUIENTES HITOS

Crecer con evidencia,
no con promesas.

  1. Alpha 0.1 · Base pública. Estandarizar el stack, estabilizar reloj y sincronización, documentar alcance y validar los flujos críticos.
  2. Alpha 0.2 · Prueba en el dojang. Medir legibilidad desde el público, manejo con teclado y comportamiento en un PC con dos monitores. Ajustar con observaciones reales.
  3. Beta · Reglas acordadas. Si se necesita torneo, definir antes la edición del reglamento, decisiones arbitrales, resultados por asalto y casos de empate.
  4. Después · Red y sensores. Diseñar roles, reconexión, autoridad del reloj y trazabilidad. Probar hardware y calibración reales antes de anunciar integración PSS.
