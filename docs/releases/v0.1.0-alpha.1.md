# PSS Taekwondo v0.1.0-alpha.1

Primera alpha web estandarizada para entrenamiento y exhibición. Un PC, un operador y una pantalla externa; puntos acumulados entre rondas.

[Abrir demo](https://protector-and-scoring-system-pss-tkdrolando.vercel.app) · [Leer guía](https://protector-and-scoring-system-pss-tkdrolando.vercel.app/guide.html)

## Qué puedes probar

- Configuración de atletas, evento, rondas y duración.
- Puntuación manual +1 a +6, Gam-jeom e impactos sin punto.
- Reloj, pausa, tiempo técnico, cambio de ronda y deshacer.
- Pantalla externa de solo lectura y un único operador por perfil del navegador.
- Resúmenes locales y exportación/importación JSON validada.
- Interfaz adaptable, navegación por teclado y guía pública.

## Base técnica

TypeScript estricto, Vite y CSS con tokens; Vitest, Playwright, axe y Prettier; GitHub Actions y el proyecto existente de Vercel. Dependencias fijadas con lockfile. Se conserva la licencia GPL v3.

## Evidencia

Cuatro pruebas unitarias y seis flujos de navegador aprobados en Chromium/Firefox, además de tipos, formato, build y CI en Linux. La demo y su guía se comprobaron sin sesión de Vercel; se probó la sincronización de puntos en producción. [Matriz y límites de verificación](../verification.md).

## Límites de esta alpha

Es experimental. No incluye sensores, homologación, reglamento WT automático, gestión de torneos ni conexión entre dispositivos. Los datos están en el navegador; exporta una copia JSON. Las ventanas deben compartir equipo, origen y perfil. La pestaña de control debe mantenerse abierta y recargarla pausa el reloj.

Queda pendiente una prueba física de sesión completa con dos monitores y revisión con lector de pantalla. El ZIP local está pospuesto por decisión del usuario.
