# Octajang

Octajang es la marca del proyecto. El nombre combina como concepto el octágono del área y el dojang de entrenamiento; es una construcción de marca, no una traducción literal del coreano.

## Presentación

- Nombre: **Octajang**. El cartel y el logotipo tipográfico usan **OCTAJANG**.
- Lema: **Cada combate, bajo control.**
- Descriptor actual: **Marcador de taekwondo para entrenamiento y exhibición**.
- Repositorio personal: `karatekah/octajang`.
- Demo: <https://octajang.vercel.app/>.

Se conserva el mismo proyecto de Vercel, renombrado como `octajang`. La dirección anterior sigue disponible para abrir y exportar los datos que pertenecen a ese origen. Un dominio propio requerirá comprobar disponibilidad y elegirlo antes de configurar otra transición.

## Identidad visual

El símbolo propio usa un octágono abierto: una mitad azul y otra roja, con dos ángulos enfrentados. Está disponible en public/assets/octajang-mark.svg y docs/assets/octajang-mark.svg. El favicon y la aplicación utilizan el mismo dibujo.

Se conservan el cinturón azul, la paleta hielo/tinta/blanco/lila/coral, las familias locales Anton, Manrope y Barlow Condensed y el movimiento aprobado. La escala del hero y las posiciones de sus gráficos se adaptan al nombre completo; la mesa mantiene puntos y reloj como prioridad.

La captura de README está en docs/assets/octajang-preview.jpg y la imagen de enlaces compartidos en public/assets/octajang-social.jpg. Títulos, metadatos, URL canónica, robots.txt y sitemap.xml utilizan la dirección efectiva de la demo. Las funciones LAN, servidor, sensores y reglamento oficial siguen pendientes.

## Compatibilidad

La marca visible y los archivos exportados usan Octajang. Los identificadores existentes de almacenamiento v4, claves v2/v3, canal local, lock y ventana pública se conservan para que el cambio de marca sea compatible en el mismo origen. El formato actual de respaldo es schemaVersion 5 para conservar las decisiones de KO; los respaldos v4 siguen siendo recuperables y se mantiene la migración de v2/v3.

Cambiar de dominio crea un origen de almacenamiento distinto. El procedimiento es exportar JSON desde la dirección utilizada, abrir la nueva e importar la copia. Control y Marcador deben permanecer en el mismo origen. La guía conserva un acceso a la dirección anterior para realizar la exportación.
